# Anthropology — recall drills, NOT Prelims simulation

Read this carefully, because it changes what you are writing.

**There is no Anthropology paper in Prelims.** The optional is examined only in
Mains, as two descriptive papers. So an Anthropology multiple-choice question
is not practice for any exam she will sit. Writing one as though it were a
Prelims question would be training her for a paper that does not exist.

What these questions are for is narrow and worth being honest about: rapid
recall maintenance on the vocabulary and attributions that a Mains answer needs
to deploy without hesitation. Terminology, thinker-to-school attribution, and
named ethnography. That is the whole purpose.

## What to ask about

- **Terminological precision.** The disciplinary vocabulary used correctly:
  descent versus filiation, sodality, avunculate, levirate and sororate,
  segmentary lineage, liminality, the incest taboo's exogamy corollary. Loose
  paraphrase is what costs marks in the Mains answer, so the drill is on the
  precise term.

- **Attribution.** Which thinker, which school, which claim. Malinowski's
  functionalism is not Radcliffe-Brown's structural-functionalism, and neither
  is Lévi-Strauss's structuralism. Misattribution in a Mains answer is a
  serious error, not a slip, and this is the cheapest way to drill it out.

- **Named ethnography.** Specific studies, specific fieldwork, specific
  communities: the Nuer, the Trobriand kula, the Jarawa, the Toda, the Andaman
  Islanders, Verrier Elwin's work, the Kula ring's actual mechanics. "Some
  tribal communities" earns nothing in a Mains answer; the named case earns
  marks. Drill the names.

## What changes about the format

The statement-based forms and every structural rule still apply — four options
naming distinct statement sets, verdicts that imply the key, time invariance,
a verifiability anchor. Those are about the question being *correct*, and that
requirement does not weaken.

What relaxes is the elimination-design pressure. A Prelims question is built to
reward partial knowledge because Prelims rewards elimination. These are recall
drills, so a question that simply checks whether she has the attribution right
is doing its job. Still keep the options as distinct statement sets and still
keep them close in length — those rules exist to stop the question being
answerable without the knowledge, which matters just as much here.

Do not write questions that would only make sense as Prelims practice:
no "which of the following is NOT a feature of" pattern-matching drills, no
questions whose difficulty comes from the option arrangement rather than from
the anthropology.

Anchor to standard sources: Ember and Ember, Nadeem Hasnain, Makhan Jha, or the
named monograph itself.
