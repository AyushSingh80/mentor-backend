# Anthropology — the theory-instance pair

This is the highest-value thing this digest can produce, and the easiest to do
badly. Read this section carefully before you fill in `anthro` on anything.

Her optional is Anthropology, examined as two Mains papers. The rubric weights
**a Paper 1 theoretical concept linked to a named Paper 2 Indian example** as
the single biggest differentiator between a 240 and a 280+ optional score. Not
knowing more theory. Not naming more communities. The LINK between the two.

So `anthro` is a claim about a pair, and it is a claim you should almost always
decline to make.

## What a link is

- `p1Slug` — the Paper 1 concept the item actually illustrates. The theory.
- `p2Slug` — the Paper 2 slug for a **concrete Indian instance the source
  itself names**: a community, a Scheduled Area, a named Act, a district, a
  specific programme.
- `usageLine` — one sentence she could write **verbatim** into a Mains answer,
  naming both the concept and the instance and stating the relation between
  them.

All three or none. The server converts a partial claim to no claim and records
it, so a half-filled `anthro` buys nothing and shows up in the log as
over-reach.

## What a link is NOT

A topical gesture. These are all worth exactly zero marks and all of them are
what an eager model produces:

- "This relates to tribal communities." — no concept, no named instance.
- "Illustrates social change." — a phrase, not a link.
- Naming a P1 concept because the *subject area* overlaps, with no instance in
  the source. Concept without instance is precisely the answer that scores 240.
- Naming a community the source never mentions, because you know one that fits.
  This is the worst case: it is a fabricated example and it will be marked as
  one if it is wrong.

## The test, applied honestly

Before you emit a link, check both halves:

1. Does the SOURCE TEXT name the instance? Not "is the instance related to what
   the source is about" — does the text in front of you name it? If not, there
   is no link, whatever the story is about.
2. Would the `usageLine` survive being written into an answer as it stands, with
   no further work? If she would have to add the concept, or add the example, or
   soften it, it is not a usage line.

## Say it plainly

**Claiming a link on everything is worse than claiming none.**

If most items in a digest carry an Anthropology link, the links are noise: she
stops reading them, and the one real link in the week is lost with the rest.
A digest where one item in five carries a link, and that one is genuine, is
worth more than a digest where five in five carry a gesture.

Most current-affairs items have no Anthropology link. That is the normal case.
Leave `anthro` empty and move on.
